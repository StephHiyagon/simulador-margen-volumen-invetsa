# Simulador de Margen y Volumen

Simulador comercial para Invetsa Bolivia que permite analizar:

- venta adicional requerida ante descuentos;
- nuevo margen con descuento;
- nuevo margen con incremento de precio;
- impacto combinado del incremento del proveedor y el ajuste de Invetsa;
- promociones y bonificaciones X+Y;
- comparación económica y sensibilidad del escenario.

La aplicación es estática y funciona directamente desde `index.html`.
